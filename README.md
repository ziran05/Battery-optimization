# Battery-optimization
This repository contains a 12-month linear programming model developed to optimize production scheduling, inventory levels, component purchasing, and capital investments for a battery manufacturing system. The model aims to minimize total operational costs while satisfying dynamic market demand under capacity and labor constraints.

# Key Features & Methodology
- Mathematical Formulation: Built a linear optimization model accounting for production, holding, purchasing, and capacity expansion costs.
- Capital Allocation: Modeled capacity expansion (K = 4,100 units/month) to evaluate internal manufacturing vs. external sourcing trade-offs (make-or-buy decisions).
- Sensitivity & Shadow Price Analysis: Analyzed dual values (shadow prices and reduced costs) to identify bottlenecks and establish maximum hourly wage thresholds for extra labor.
- Stress Testing: Conducted \pm 20\% demand scenario analyses to test model robustness and system resilience.

# Tools Used
- Excel Solver / Linear Programming
- Sensitivity & Scenario Analysis
